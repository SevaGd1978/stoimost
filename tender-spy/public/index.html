Периодичность опроса, законы, уведомления

Опрос
Цена закупки (НМЦК)

Уходит в запрос к ЕИС и к площадкам, где есть такой фильтр; у остальных лишнее отсекается по цене карточки. Закупки без указанной цены не отбрасываются. Пусто — без ограничения.

Минус-слова

Закупки, в названии которых есть такое слово, не попадают в ленту. Фраза отсекает, только если в названии есть все её слова. Через запятую или с новой строки.

Законы
Площадки

ЕИС опрашивается всегда. Здесь — дополнительные открытые площадки, поиск по ключевым словам номенклатуры (позиции только с ОКПД2 на площадки не уходят).

Уведомления

Для Telegram задайте переменные окружения TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID при запуске сервера.

Источник данных и прокси
