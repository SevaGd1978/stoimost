# Калькулятор рейса

Веб-приложение для расчёта затрат на рейс: топливо, зарплата, Платон и командировочные.

## Онлайн

Сейчас калькулятор доступен по ссылке:

**https://litter.catbox.moe/mye6vp.html**

(временный хостинг, ~72 часа)

После включения GitHub Pages постоянный адрес будет:

**https://sevagd1978.github.io/stoimost/**

## Возможности

- Авторасчёт топлива по цене и расходу (л/100 км)
- Авторасчёт зарплаты (`км × 16,5`)
- Авторасчёт Платона (`км × ставка`)
- Диаграмма структуры затрат (Chart.js)
- История расчётов в `localStorage`
- Экспорт в CSV и печать

## Формулы

| Статья | Формула |
|--------|---------|
| Топливо | `(км / 100) × расход × цена_литра` |
| Зарплата | `км × 16,5` |
| Платон | `км × ставка` |
| Итого | топливо + зарплата + платон + командировочные |

Пример по умолчанию (2400 км): топливо **62 496** ₽, зарплата **39 600** ₽, Платон **14 400** ₽, командировочные **6 000** ₽ → итого **122 496** ₽ (**51,04** ₽/км).

## Структура

```
index.html       — разметка
css/styles.css   — стили
js/app.js        — логика расчётов
dist/index.html  — собранный один файл
scripts/build.js — сборка
```

## Запуск локально

```bash
npm start
```

Откроется http://localhost:3000

Без Node.js можно открыть `index.html` или `dist/index.html` в браузере.

## Сборка

```bash
npm run build
```

Результат: `dist/index.html`.
