# Калькулятор рейса

## Онлайн

Публичная ссылка появится после деплоя (см. PR / README).

Веб-приложение для расчёта затрат на рейс: топливо, зарплата, Платон и командировочные.

## Возможности

- Авторасчёт топлива по цене и расходу (л/100 км)
- Авторасчёт зарплаты (`км × 16,5`)
- Авторасчёт Платона (`км × ставка`)
- Диаграмма структуры затрат (Chart.js)
- История расчётов в `localStorage`
- Экспорт в CSV и печать

## Структура

```
index.html      — разметка
css/styles.css  — стили
js/app.js       — логика расчётов
scripts/build.js — сборка в один HTML
```

## Запуск

```bash
npm start
```

Откроется локальный сервер на [http://localhost:3000](http://localhost:3000).

Без Node.js можно просто открыть `index.html` в браузере.

## Сборка

```bash
npm run build
```

Результат: `dist/index.html` — один файл со встроенными CSS и JS.
